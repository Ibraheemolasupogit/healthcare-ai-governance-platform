# Data

**Synthetic data only** — see ADR
[0001](../docs/architecture/decisions/0001-synthetic-data-only.md). No real patient, clinician, or
institutional data will ever be placed in this directory.

## Current status

Empty. As of Milestone 2, the synthetic dataset/model/research-project inventory is generated by
`src/governance_platform/inventory/` and written to
[`outputs/inventory/`](../outputs/README.md) (gitignored, reproducible via
`python scripts/generate_inventory.py`) rather than committed under this directory — see the root
[README's Inventory outputs section](../README.md#inventory-outputs). `data/synthetic/` remains
scaffolded for future synthetic data that later milestones (e.g. access-grant or audit-event
simulation) may generate.

## Intended future contents

- `data/synthetic/` — reserved for future synthetic access and audit data used to exercise later
  governance planes, clearly labelled as synthetic at the point of generation.
